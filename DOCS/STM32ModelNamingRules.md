# STM32 型号命名规则详解

STM32 的完整型号遵循一个标准格式，其核心部分可以表示为：**STM32 `X` `Xxx` `Y` `Z` `M` `C` `T` `*6***`**。

> **注意**：并非所有系列都有完全相同的位数，但核心部分的规则是一致的。具体参数请务必以官方数据手册为准。

我们以 **STM32 F 103 R C T 6** 为例进行分解：

| 部分 | 示例 | 含义 | 其他常见选项及含义 |
| :--- | :--- | :--- | :--- |
| **1. 产品系列** | **STM32** | 基于 ARM Cortex-M 内核的 32 位微控制器 | 这是所有 STM32 微控制器的前缀。 |
| **2. 产品类型** | **F** | **基础型 / 通用型** | **L**: 超低功耗型 (e.g., STM32L4)<br>**H**: 高性能型 (e.g., STM32H7)<br>**W**: 无线型 (e.g., STM32WB)<br>**G**: 主流型 (e.g., STM32G0)<br>**MP1**: 微处理器 (MPU) |
| **3. 产品子系列** | **103** | **特定子系列** (Cortex-M3 内核，基础性能) | **F1 系列**: 101, 102, 103, 105, 107<br>**F4 系列**: 405, 407, 411, 427, 429<br>**L4 系列**: 431, 451, 471, 476, 486<br>**G0 系列**: 030, 070, 071<br>**H7 系列**: 743, 750, 7B3<br>*(数字通常代表性能、外设和内存的增强)* |
| **4. 引脚数目** | **R** | **64 引脚** | **F**: 20 引脚<br>**G**: 28 引脚<br>**T**: 36 引脚<br>**C**: 48 引脚<br>**U**: 63 / 64 引脚 (WLCSP)<br>**V**: 100 引脚<br>**Z**: 144 引脚<br>**I**: 176 引脚<br>*(具体引脚数需查数据手册确认)* |
| **5. Flash 容量** | **C** | **256 KB** | **4**: 16 KB<br>**6**: 32 KB<br>**8**: 64 KB<br>**B**: 128 KB<br>**C**: 256 KB<br>**D**: 384 KB<br>**E**: 512 KB (e.g., STM32F407**VET**6)<br>**F**: 768 KB<br>**G**: 1024 KB (1 MB)<br>**I**: 2048 KB (2 MB)<br>***(此编码规则因系列而异，F1/F4 通用，但新系列如 G0 可能不同)*** |
| **6. 封装类型** | **T** | **LQFP** | **H**: BGA<br>**T**: LQFP<br>**U**: UFQFPN (超薄 Fine-pitch QFN)<br>**Y**: WLCSP (晶圆级芯片规模封装) |
| **7. 温度范围** | **6** | **-40°C 到 85°C** (工业级) | **6**: -40°C 到 85°C<br>**7**: -40°C 到 105°C<br>**3**: -40°C 到 125°C (扩展工业级/车规级)<br>**C**: 0°C 到 70°C (商业级，现已少见) |
| **(可选) 8. 选项** | *(此型号无)* | 用于表示特殊功能或版本 | **A**: 含模拟选项 (较少见)<br>**V**: 汽车级 (与温度范围结合，如 `3V`)<br>**T**: 符合汽车级标准 (另一种表示)<br>**P**: 含 PHY (例如带以太网 PHY 的型号) |

---

## 举例说明

- **STM32F103RCT6**:
  - **F**: 基础型
  - **103**: Cortex-M3 子系列
  - **R**: 64 引脚
  - **C**: 256 KB Flash
  - **T**: LQFP 封装
  - **6**: 工业级温度范围

- **STM32F407VET6**:
  - **F**: 基础型
  - **407**: 高性能 Cortex-M4F 子系列 (带 FPU)
  - **V**: 100 引脚
  - **E**: 512 KB Flash
  - **T**: LQFP 封装
  - **6**: 工业级温度范围

- **STM32L432KCU6**:
  - **L**: 超低功耗型
  - **432**: Cortex-M4F 超低功耗子系列
  - **K**: 32 引脚 (WLCSP)
  - **C**: 256 KB Flash
  - **U**: UFQFPN 封装
  - **6**: 工业级温度范围

## 总结

通过解析 STM32 的型号，我们可以快速了解一颗芯片的核心特征（内核类型、性能定位、引脚数、存储大小等），这对于芯片选型和替代至关重要。**最可靠的方法是结合此命名规则和意法半导体（ST）官方发布的** [数据手册 (Datasheet)](${官方链接}) **与** [参考手册 (Reference Manual)](${官方链接}) **进行最终确认。**
