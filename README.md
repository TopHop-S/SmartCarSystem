## 📌 项目简介

本项目基于 **STM32F407VET6** 最小系统，结合 **BTS7960B驱动模块** 与 **MG370P34 12V电机**，实现车载电机的精准控制。<br/>
项目将搭建一个嵌入式系统，支持人机交互、传感器采集、电机控制、安全保护、数据记录以及 Bootloader OTA 升级在内等多种功能，模拟车载ECU的实际应用场景。

## ⚡ 硬件清单

| 部件 | 型号/规格 |
| :--- | :--- |
| **主控MCU** | STM32F407VET6 最小系统板 |
| **电机** | MG370P34 (12V) |
| **电机驱动** | BTS7960B 半桥驱动模块 |
| **电源** | 12V 5000mAh 锂电池 |
| **降压模块** | LM2596S (12V → 5V/3.3V) |
| **人机交互** | 2.8 寸 TFT LCD 触摸屏|
| **调试器** | ST-Link V2 |

## ✨ 核心特性

- **🎛️ 精确电机控制**：基于 PWM 的软启动、正转、反转、刹车及转速调节。
- **👆 友好人机交互**：2.8 寸触摸屏提供菜单导航、参数设置和实时数据监控。
- **🛡️ 全面安全机制**：包含欠压、过压、过流及过温保护，确保系统稳定运行。
- **💾 数据持久化**：关键参数非易失存储（NVS），掉电不丢失。
- **🚀 OTA 远程升级**：集成 Bootloader，支持通过串口进行固件远程更新，易于功能扩展和维护。
- **🔌 标准通信接口**：预留 CAN 总线接口，具备融入真实车载网络的能力。

## 🛠️ 功能初步规划

### 1. 电机驱动与控制
- PWM 占空比调节，实现电机转速可控

### 3. 数据管理
- 参数存储（NVS，掉电保持）
- 电机运行日志记录

### 4. 人机交互
- 实时数据显示（转速、电流、电压等）

### 5. OTA 升级 (Bootloader)
- Flash 分区：Bootloader + 应用分区
- 远程固件刷新，支持串口/蓝牙扩展
- 满足车载 ECU 常见升级需求

## 🛠️ 系统架构与功能

### 1. 电机驱动与控制
- 生成高频 PWM 信号控制电机转速和方向。
- 实现平滑的软启动/软停止逻辑，减少机械冲击。
- 实时监测驱动芯片状态，实现过流、过温保护。

### 2. 人机交互 (HMI)
- 触摸屏 GUI 界面，包含主状态页、设置页和调试页。
- 可实时显示电机转速、总线电压、工作电流、系统温度等参数。
- 通过触摸屏设置转速目标值、电流限制等参数。

### 3. 数据管理与存储
- 使用片内 Flash 或外置 EEPROM 模拟 NVS (Non-Volatile Storage)。
- 存储用户设置参数（如最大转速、保护阈值）和系统运行日志。

### 4. 安全保护机制
- **电气安全**：实时 ADC 采样，监测电源电压和电机电流，触发硬件保护。
- **硬件保护**：利用驱动芯片的使能端和故障诊断引脚实现快速关断。
- **软件保护**：在异常状态下（如堵转、温度过高）自动进入安全模式。

### 5. OTA 升级 (Bootloader)
- Flash 内存划分为 Bootloader 区和应用主程序区。
- Bootloader 通过串口通信，接收新固件并校验烧录。
- 支持手动进入升级模式和应用程序触发升级流程。

</details>
